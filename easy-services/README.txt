Coffeebreak Easy Services - concept demo
by Karen Elizabeth O'Brien (Coffeebreak), Newcastle NSW - https://coffeebreaks.itch.io

How to open: unzip, then open index.html in any web browser (phone, tablet or computer). Works offline.

This is a design concept only. It is not a government service and is not affiliated with myGov, Services Australia, Medicare, NDIA or Centrelink. It uses only made-up sample data (Sam Sample), never asks for real logins or numbers, and sends nothing anywhere. Data you try out is kept only in this browser on this device.

One sign-in: the big "Sign in with myGov" button on Home opens the official myGov website (https://my.gov.au) in a new tab. myGov links Centrelink, Medicare and the NDIS, so one sign-in opens them all. You sign in once on the official myGov site. Coffeebreak never sees your login. The app never asks for, stores or fills in any login, password, code or number.
