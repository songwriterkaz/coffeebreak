Coffeebreak WiFi Hotspot

The kit

This page is the downloadable Coffeebreak WiFi hotspot and local mail kit. It is the captive-portal welcome page plus setup scripts for Windows, macOS and Linux, and a separate local mail server for people on that hotspot.

Both programs need Node.js 18 or newer on the computer that shares the connection. They do not include an account password, a relay password, or a deploy key.

Why switch

  • One US$10 purchase. No monthly fee for the software.
  • Share one existing data plan through a phone or laptop hotspot.
  • Free local mail between people on the hotspot, when the host runs the local Coffeebreak Mail server on that same computer.

Coffeebreak does not give free internet. Data used on the hotspot counts on the host's plan. Local mail only works while that phone or laptop is sharing the connection.

The welcome page in the kit says one US$10 purchase, with no monthly fee for the software. Internet access comes from the host's own provider.

Windows

  1. Install Node.js 18 or newer.
  2. Unzip the WiFi kit. In the coffeebreak-wifi/server folder, open PowerShell as Administrator.
  3. Run powershell -ExecutionPolicy Bypass -File setup\windows-mobile-hotspot.ps1
  4. When asked, choose a hotspot password of 8 or more characters. The network name is Coffeebreak WiFi. The password stays on that PC. It is not in this download.
  5. The script shares this PC's existing internet connection and allows the welcome page through the firewall on port 80.
  6. Start the portal with node server.js, or run setup\start-windows.bat as Administrator.
  7. Windows hotspots usually use the address 192.168.137.1. Guests open http://192.168.137.1
  8. Windows does not send guests to that page by itself. Put the address on a sign or a QR code.

macOS

  1. Install Node.js 18 or newer.
  2. Open System Settings, then General, then Sharing, then Internet Sharing.
  3. Share your connection from Ethernet, iPhone USB, or Thunderbolt. That is the Mac's internet.
  4. Share to devices using Wi-Fi.
  5. In Wi-Fi Options, set the network name to Coffeebreak WiFi, choose WPA2 or WPA3 Personal, and set a password.
  6. Turn Internet Sharing on. The Mac's Wi-Fi cannot share the same Wi-Fi network it is already joined to. Use Ethernet or a phone over USB.
  7. From the coffeebreak-wifi/server folder, run sudo bash setup/macos-internet-sharing.sh
  8. Guests open the address the script prints. macOS does not send guests to that page by itself. Put the address on a sign or a QR code.

Linux, with the welcome page redirect

This path is written for Debian, Ubuntu, and Raspberry Pi OS. It needs hostapd, dnsmasq, iptables, ipset, and Node.js 18 or newer. From the coffeebreak-wifi/server folder:

sudo apt install hostapd dnsmasq iptables ipset nodejs
sudo bash setup/linux-hotspot-captive.sh start
  1. The Wi-Fi card defaults to wlan0 and the internet connection defaults to eth0. Override them with WIFI_IF and WAN_IF if your machine uses other names. A phone tether is often usb0.
  2. The network name defaults to Coffeebreak WiFi. Set PASS to 8 or more characters, or leave it empty for an open network. Set it in the environment for that command. Do not put it in a file you publish.
  3. Guests can open http://192.168.50.1/ or http://coffeebreak.wifi/. Until a device accepts the terms, its web requests go to the welcome page.
  4. To stop, press Ctrl+C in the portal window, then run sudo bash setup/linux-hotspot-captive.sh stop

Linux, NetworkManager only

Use this when you want the hotspot and the welcome page without hostapd. It does not redirect guests on its own.

sudo bash setup/linux-networkmanager-hotspot.sh
  1. The script asks for a hotspot password of 8 or more characters. The default Wi-Fi card is wlan0. Override it with WIFI_IF if needed.
  2. Guests open the address the script prints. Put that address on a sign or a QR code.

Local mail on the hotspot

The mail download is a local SMTP and API server for addresses at coffeebreak.local. It is for people on the hotspot. It is not the public mail website, and it does not contain a deploy credential.

  1. Unzip coffeebreak-mail-local-hotspot.zip.
  2. In coffeebreak-mail/server, copy config.example.json to config.json.
  3. Leave outside mail turned off for mail between people on the hotspot. The example file uses placeholders only. If you later add your own relay, keep that only in config.json on the host computer. That file is ignored by the kit and must not be published.
  4. Run npm install and then npm start.
  5. SMTP receives mail on port 25. The API listens on port 8080.
  6. Create a mailbox with node src/cli.js add-user username. Type the password when asked, or pass it only in the PASSWORD environment variable for that one command.
  7. When this server is running, the WiFi welcome page can show a link to Coffeebreak Mail on port 8080.

The web folder in the mail zip has the Coffeebreak logo. reference-ui-from-live is a copy of the public mail screen, kept so a local front end can be adapted from it. It is not a Cloudflare deploy. That screen calls the public mail service unless it is opened on localhost, because that is how the copy was written. Mail between people on the hotspot is the SMTP and API server in the zip.
