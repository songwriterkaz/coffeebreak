Set up your Coffeebreak Phone X

In the box: Phone X, FREE Wi-Fi Smart Glasses and FREE stylus. Pair the glasses in the 🕶️ Glasses app; use the stylus in ✍️ Handwriting Notes and 🎨 Draw.

Works on the physical Coffeebreak Phone X (Wi-Fi only, no SIM) and on any phone's browser. Nothing to download.

  1. Connect to Wi-Fi: Settings → Network & internet → Wi-Fi → pick your network.
  2. Open the link: open Chrome (or Safari on iPhone) and go to the Coffeebreak Phone X page on itch.io, then tap Run game / Open full screen.
  3. Add to Home Screen:
    Android / Coffeebreak Phone X: Chrome menu ⋮ → Add to Home screen / Install app.
    iPhone: Share ⬆ → Add to Home Screen.
  4. Make it the main app (Coffeebreak Phone X): long-press the Coffeebreak icon and drag it to the dock. It opens full screen like a built-in app and keeps working offline.
  5. Allow camera/mic when asked, for calls and video. Notes, contacts and settings stay on the phone.
