What has to exist before a real charge

  • Karen's own Stripe platform account, with Connect enabled, and the secret key stored only as a server secret.
  • A webhook signing secret on that same server. Events are accepted only after the signature matches.
  • Each seller's own connected account id. The browser cannot choose an account that the server does not already have.
  • An agreed platform fee in basis points. No rate is stored here, so no share is calculated.
  • A deliberate server flag before any Checkout Session is created.

Until those are set, this page does not start a payment, transfer, or payout. PayID stays available as a separate manual bank transfer. It is not instant and it is not automatic.
