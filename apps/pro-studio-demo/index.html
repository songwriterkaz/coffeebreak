ℹ️ How recording works

1. Pick your input type and mic model. 2. Open the input and set preamp gain so speaking/singing lights SIG green, never CLIP. 3. On the Studio tab arm an Audio track (R button) and press ⏺. Arm an instrument track instead to record MIDI from the on‑screen keyboard or a MIDI keyboard. Latency is auto‑compensated; fine tune below.

Condenser mics need 48V phantom power. Ribbon mics: keep 48V off. Guitars & basses straight in? Use Instrument input with Hi‑Z on.
